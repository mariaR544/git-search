# GIT-SEARCH 🚀
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

GIT-SEARCH es una plataforma de escritorio profesional construida con Electron y Node.js que permite realizar análisis visuales profundos sobre repositorios de código Git (locales y remotos). Ofrece métricas avanzadas como mapas de calor interactivos (Didactic Heatmap), rankings de inestabilidad de archivos (Churn), gráficas de colaboración en equipo (Sinergia), exportación de informes a PDF, descarga instantánea universal de código fuente (ZIP) y un Asistente de Inteligencia Artificial nativo (impulsado ultrarrápido por Groq/LLaMA-3) capaz de responder preguntas analíticas en base al contexto estructural completo del proyecto.

## 🛠️ Instalación y Uso

git clone https://github.com/JuanMarcano-unimar/git-search.git
cd git-search
npm install (Esto descargará todas las librerías que ocultamos con el .gitignore).
npm start

Asegúrate de tener instalado [Node.js](https://nodejs.org/) y [Git](https://git-scm.com/) en tu sistema.

1. **Clona o descarga el proyecto** a tu máquina.
2. **Abre la terminal** en la carpeta raíz (`/git-metrics-analyzer`).
3. **Instala las dependencias principales:**
   ```bash
   npm install
   ```
4. **Inicia la plataforma de escritorio:**
   ```bash
   npm start
   ```
   *(Para empaquetar un archivo instalable `.exe`, ejecuta `npm run dist`).*
